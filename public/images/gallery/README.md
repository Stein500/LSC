# 🖼️ Galerie — Les Services Colombes

Ce dossier contient les **images des galeries** des pages du site.

## 📁 Convention de nommage

| Format | Extension | Qualité |
|---|---|---|
| **WebP** (recommandé) | `.webp` | qualité 80 |
| Fallback legacy | `.jpg` | qualité 85 |

> ⚠️ **Tout est en WebP** — ne pas utiliser de `.svg`, `.png` ou autres extensions.
> Le composant `PageHero` convertit automatiquement toute autre extension en `.webp`.

## 📐 Specs recommandées

- **Format** : WebP (qualité 80)
- **Dimensions** : 1600×1200 minimum (ratio 4:3)
- **Poids** : < 250 Ko par image
- **Style** : Lumière naturelle, ambiance atelier Porto-Novo, tons chauds (corail, or, beige)
- **Palette** : orange / jaune / vert / rouge wax + beige / ocre
- **Logo** : filigrane "Les Services Colombes" en doré, coin bas-droit, opacité 30%, ne couvrant pas le sujet

## 💡 Astuce

Utilise [squoosh.app](https://squoosh.app) (gratuit, dans le browser) pour convertir et compresser en WebP en 2 clics.
